# Architecture decision records

One short record per major choice. Number them in order (`0001-...md`). Keep each under a page, and link every technical claim to official documentation.

## Template

```markdown
# NNNN. Title

Date: YYYY-MM-DD · Status: Accepted | Superseded by NNNN

## Context
What question had to be answered, and what constraints shaped it.

## Decision
What was chosen, in one or two sentences.

## Consequences
What gets easier, what gets harder, and what would change at client scale.

## References
Links to official docs that back the claims above.
```

The first set of records is tracked in the M0.5 issue.
